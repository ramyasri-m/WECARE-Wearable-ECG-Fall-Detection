# WECARE Mobile

React Native 0.76.5 app (TypeScript). It scans for nearby Bluetooth LE devices, flags
those within the WECARE bystander range (RSSI >= -70 dBm, about 10 m), publishes the
best reading to ntfy, and shows emergency alerts pushed by the orchestration engine.

## Build and run (Android)

Requirements: Node 18+, JDK 17, Android Studio (or the Android SDK with
`ANDROID_HOME` set), and a **physical** Android phone with USB debugging on.
BLE scanning does not work on emulators.

```bash
cd mobile
npm install
npx react-native run-android
```

The first Gradle build downloads dependencies and takes several minutes.

## Checks

```bash
npm run typecheck   # tsc --noEmit
npm run lint
npm test            # renders the scanner screen with BLE mocked
```

## What the app does

| Feature | Detail |
|---------|--------|
| BLE scan | 15 s scan, devices sorted by signal strength |
| Distance | Apple EN formula `d = 0.89976 * (RSSI/TxPower)^7.7095 + 0.111` |
| Bystander range | RSSI >= -70 dBm |
| Publish | After each scan, posts to `ntfy.sh/wecare-demo-ble` |
| Alerts | Polls `ntfy.sh/wecare-demo` every 5 s and shows HIGH/MEDIUM alerts with instructions |

The ntfy topics are public and unauthenticated. Anyone who knows the topic names can read
or post to them, so do not send real patient data through them.

## Permissions

| Android | Permissions |
|---------|-------------|
| 12+ (API 31+) | `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT` |
| 11 and below | `ACCESS_FINE_LOCATION`, `BLUETOOTH`, `BLUETOOTH_ADMIN` |

## Status

Verified: TypeScript passes, lint has no errors, the Jest render test passes, the Android
JS bundle builds, and `react-native-ble-plx` and `react-native-permissions` autolink.

Not verified: a full Gradle APK build and running on a device. Neither could be done in
the environment this was written in, because it had no Android SDK and could not reach
`dl.google.com`. Run `npx react-native run-android` on your machine to confirm.
iOS is not set up for BLE (needs `NSBluetoothAlwaysUsageDescription` in `Info.plist`).
